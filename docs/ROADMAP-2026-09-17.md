### 2.1 ✅ P1-1: `_active_profile_name` fallback 到 "default" 掩盖 profile 串台 → **已修(改为 warning)**

- **测试**: `tests/agent/test_audit_2026_09_17_profile_name_warning.py` (2 个 INVARIANT)
- **回归**: `test_bot_profile_prompt_isolation.py` + `test_profile_home_override_precedence.py` 全绿

## 3. 子任务误判(不修)❌

### 3.1 P0-3: `gateway/run.py:253` copy_context override
- **子任务报告说**: 异常路径下 copy_context().run 可能泄漏 override
- **校对结论**: ❌ **不是 bug**。`copy_context()` 在 Python 标准库语义上保证 ContextVar 跨线程传播。
- **证据**: 读 `gateway/run.py:251-253` 与 L1843-1844,两处都是 `with _profile_runtime_scope(...): loop.run_in_executor(None, copy_context().run, fn)`,with 块**进入时**设的 override 会被 `copy_context()` 抓到。
- **处理**: 不动。

### 3.2 P1-1: `system_prompt.py` 5 处 except(实际 16 处)
- **子任务报告说**: 5 处 except 最危险
- **校对结论**: ⚠️ **多数是正确设计**。
- **证据**:
  - L126-132: fallback 到 previous snapshot / 空 tuple + 日志 = cache-stable 标准做法 ✅
  - L89 `cwd=""`: 降级显示 ✅

  - **唯一真隐患**: L108 `return "default"`(见 §2.1)
- **处理**: 仅修 L108(已计入 §2.1),其他 15 处不动。
