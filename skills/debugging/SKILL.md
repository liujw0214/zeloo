# Debugging 技能

当用户报告 bug、报错、异常行为或"不工作"时激活本技能。

## 工作流程

### 1. 信息收集
- 获取完整错误信息（堆栈、退出码、日志片段）
- 确认复现步骤和环境（OS、Python 版本、依赖版本）
- 确认是否最近有变更（配置、代码、依赖）

### 2. 复现问题
- 尝试最小复现步骤
- 如果无法复现，记录环境差异
- 检查是否为时序/并发相关问题

### 3. 根因定位（二分法）
- 从错误堆栈的最内层开始分析
- 逐层向上追溯调用链
- 在可疑位置添加日志或使用 `execute_code` 运行诊断脚本
- 区分：代码逻辑 bug / 配置错误 / 依赖问题 / 环境问题

### 4. 修复方案
- 给出最小修复（只改根因，不大范围重构）
- 解释修复原理
- 检查是否有同类问题需要一并修复

### 5. 验证
- 复现步骤验证修复生效
- 运行相关单元测试
- 检查无回归

## 常见排查清单

| 现象 | 优先检查 |
|------|----------|
| ImportError | 依赖是否安装、路径是否正确 |
| ModuleNotFoundError | PYTHONPATH、虚拟环境 |
| PermissionError | 文件权限、沙箱白名单 |
| 超时 | 网络、死循环、资源耗尽 |
| 编码错误 | 文件 encoding、UTF-8 BOM |
| NoneType 错误 | 空值检查、初始化顺序 |
