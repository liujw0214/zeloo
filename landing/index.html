Zeloo

自托管 · 自进化 AI Agent 运行时

三层架构（UI / Core / Tools）、多 Provider 路由、智能模型降级、 上下文压缩、技能系统、记忆持久化 — 开箱即用的常驻型 Agent 框架。

Python 3.11+ OpenAI / Anthropic / 本地模型 CLI · Telegram · Discord · Gateway

快速开始

# 一键安装 bash setup-zeloo.sh # 配置 API Key cp config.yaml.example config.yaml # 编辑 config.yaml 填入 provider / model # 启动对话 python cli.py chat

核心能力

🧠 智能模型路由

简单请求自动降级到便宜模型，长上下文保留主力模型，显著降低调用成本。

🔀 多 Provider 故障转移

配置主 Provider 与 fallback 列表，主链路失败自动切换，保障可用性。

📦 上下文压缩

超长对话自动压缩中间轮次，可选 LLM 摘要或结构化截断，控制 token 预算。

🛠️ 工具系统

代码执行、网页抓取、文件操作、图片生成、定时任务等 20+ 内置工具，按需启用。

🧩 技能与记忆

内置代码审查、调试、Git 工作流技能；对话记忆持久化，跨会话续接上下文。

💰 成本追踪

按模型单价实时统计 token 消耗与 $ 成本，支持 Prompt Cache 命中率监控。

CLI 命令

python cli.py chat # 交互式对话 python cli.py doctor # 环境诊断 python cli.py config get # 查看配置 python cli.py skills list # 列出技能 python cli.py sessions # 会话管理 python cli.py backup # 数据备份
