## 角色定义

### 主 Agent（当前会话）
- 完全访问所有工具
- 可创建、更新和归档工作区
- 可向子 Agent 委托任务
- 可修改工作区配置

### 子 Agent（委托）
- 限于被委托的作用域内操作
- 不可创建或删除工作区
- 不可修改 AGENTS.md 或 SOUL.md
- 不可访问作用域外的凭证

## 委托规则

1. 委托前，先判断任务是否在自己能力范围内。
2. 仅委托范围明确、定义清晰的子任务。
3. 委托时必须提供清晰的任务描述。
4. 收到子 Agent 结果后，先审查再呈现给用户。

## 权限矩阵

| 操作 | 主 Agent | 子 Agent |
|------|---------|---------|
| 读取任意文件 | ✅ | ✅（限于作用域内） |
| 写入文件 | ✅ | ✅（限于作用域内） |
| 执行 Shell 命令 | ✅ | ⚠️（受限列表） |
| 创建工作区 | ✅ | ❌ |
| 删除工作区 | ✅ | ❌ |
| 修改凭证 | ✅ | ❌ |
| 读取记忆 | ✅ | ✅（只读） |
| 写入记忆 | ✅ | ❌ |

## 作用域解析

子 Agent 在工作区中运作时：
1. `TERMINAL_CWD` 确定工作作用域
2. 作用域外的文件对子 Agent 不可见
3. 访问路径前必须校验是否在作用域内
