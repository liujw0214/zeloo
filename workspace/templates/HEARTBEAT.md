## 如何添加任务

使用 `cron_add` 工具：

```
cron_add(name="my_task", schedule="0 9 * * *", command="echo '早上好'")
```

## Cron 调度格式

- `N * * * *` — 每 N 分钟
- `0 N * * *` — 每 N 小时
- `0 0 * * *` — 每天午夜
- `0 9 * * 1-5` — 工作日早上 9 点

## 任务执行

任务通过心跳循环在后台运行。每个任务：
1. 将计划时间与系统时间对比
2. 如果到期则执行（且上次运行已完成）
3. 将输出记录到 `workspace/logs/heartbeat.log`
4. 更新本文件的"上次运行"列

## 监控

查看任务运行状态：
```bash
tail -f workspace/logs/heartbeat.log
```

查看执行历史：
```bash
cat workspace/logs/cron_history.json
```
